## 0.2.0 (2026-11-09)

### ⚠ BREAKING CHANGES

* **provenance:** `compare_versions` renames its result fields:
  `unified_diff` → `rendered_diff`, `added_chunks` → `added`,
  `removed_chunks` → `removed`. The `max_chunks_per_side` argument is gone —
  the server caps its own payload. Inputs are otherwise only loosened, so
  existing calls still validate.

### Features

* **provenance:** `compare_versions` now diffs server-side via
  `GET /v1/document_versions/{id}/diff` instead of paging every chunk of both
  versions into the process. Reports `diff_format` / `unit` (text lines,
  spreadsheet cells, structured fields or document blocks) plus `truncated` and
  `degraded`. ([#196](https://github.com/knowledgestack/ks-mcp/pull/196))
* **workflows:** new read-only `get_workflow_status` tool, so a caller can tell
  "still running" from "failed" after an `ask` times out.
  ([#197](https://github.com/knowledgestack/ks-mcp/pull/197))
* **prompts:** MCP `prompts/` library — `summarize-with-citations`,
  `compare-documents`, `expand-around-chunk`, `answer-from-folder`.
  ([#198](https://github.com/knowledgestack/ks-mcp/pull/198))
* **schemas:** per-tool JSON Schema published under `schemas/`, generated by
  `scripts/export_schemas.py` and drift-checked in CI.
  ([#199](https://github.com/knowledgestack/ks-mcp/pull/199))
* **deploy:** reference `Dockerfile` plus Fly.io / Cloud Run / Modal configs,
  and a `GET /healthz` liveness route.
  ([#200](https://github.com/knowledgestack/ks-mcp/pull/200))
* **resources:** folders and documents addressable as `ks://` MCP resources.
  ([#201](https://github.com/knowledgestack/ks-mcp/pull/201))

### Bug Fixes

* **browse:** `list_contents` and `find` advertised `limit` up to 200, but the
  KS folder endpoints cap it at 100 and the SDK rejects 101 client-side with a
  raw validation error. Both are now `le=100`.
* **schemas:** tool descriptions are normalized with `inspect.cleandoc`, so the
  published schemas are byte-identical on every supported Python. Python 3.13
  dedents docstrings at compile time and 3.11/3.12 do not, which previously
  made the export interpreter-dependent.

### Security

* **deploy:** `KS_ALLOWED_HOSTS` / `KS_ALLOWED_ORIGINS`. FastMCP only
  auto-enables DNS-rebinding protection for a localhost bind, so a container
  binding `0.0.0.0` accepted any `Host` or `Origin` header while holding a
  tenant API key. Set `KS_ALLOWED_HOSTS` on any hosted deployment.

## 0.1.0

Initial public beta: read-only tool surface over the Knowledge Stack API —
`ask`, `extract`, `search_knowledge` / `search_keyword` / `search_hybrid`,
`read` / `read_around`, `cite`, `list_contents` / `find` / `get_info`,
`view_chunk_image`, `get_organization_info` / `get_current_datetime`,
`trace_chunk_lineage` / `compare_versions`, over stdio and Streamable HTTP.
